# MP4 Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a local Mac qView fork that autoplays original MP4 files on repeat alongside images.

**Architecture:** Qt6 QMediaPlayer and QGraphicsVideoItem share the existing view with the pixmap item. Core owns playback lifecycle; the view owns scene geometry; window/actions consume media-neutral controls.

**Tech Stack:** C++14, Qt6 Multimedia/MultimediaWidgets, CMake, QtTest.

**Spec:** docs/superpowers/specs/2026-11-13-mp4-loop-design.md

## Global Constraints

- Mac target, full source resolution and no transcoding.
- MP4 autoplay, infinite repeat, mixed folder navigation, existing zoom/fullscreen.
- Audio muted by default; M toggles mute.
- Keep isMovieLoaded specific to QMovie; add isVideoLoaded. isPixmapLoaded remains the ready-content flag used throughout existing code.
- Preserve GIF-only stepping/saving; skip MP4 in image preloading.
- Deliver separate qView Loop.app and distinct settings/bundle identity; no publishing.

## Review Focus

- Late video/image completion after navigation must not revive old content.
- Portrait/rotated videos must retain correct aspect ratio and fit bounds.
- Loop boundaries must preserve zoom and not reset window/recents.
- Corrupt/unsupported MP4 must leave navigation usable.
- Leaving, renaming, deleting and closing video must release playback.
